# ohmysource

> **Background Context:** Following the internet shutdown in Iran (starting February 28th), this repository serves as a mirror/fetching tool for [PsiphonOverMITM](https://github.com/B3hnamR/PsiphonOverMITM) - a project that is currently blocked by Iranian internet service providers.

## Purpose
This repository uses GitHub Actions to fetch the source code from the original repository, making it available for download within Iran where direct access is restricted.

## How it works
- A GitHub Actions workflow automatically fetches the source from the original repository
- The fetched source is stored as an artifact and directly in this repository
- Users in Iran can download the source from this mirror repository

## For Iranian Users
If you cannot access the original repository due to internet restrictions, you can:
1. Download the `myfile.zip` from this repository
2. Or check the **Actions** tab for the latest artifact
3. Or simply download the entire repository as ZIP
